# Tkinter-Animated-Moving-Window-
Tkinter Animated Moving Window

A simple Python GUI project built with Tkinter that creates a small borderless window and animates it around the edges of the screen.

The window changes color as it reaches each side of the screen, creating a simple rectangular animation.

Demo

The application creates a small 40×40 pixel window that:

Starts at the top-left corner.
Moves from left to right.
Changes color when it reaches the right side.
Moves down.
Changes color when it reaches the bottom.
Moves right to left.
Changes color when it reaches the left side.
Moves up toward the starting position.

The animation continuously repeats.

Features
🖥️ Tkinter GUI
🎯 Dynamic screen-size detection
🪟 Borderless window using overrideredirect()
📌 Always-on-top window
🎨 Color changes at each direction
⏱️ Non-blocking animation using after()
🔄 Continuous movement around the screen
🧱 Object-oriented implementation using a Python class
